ระบบ BKK Flood Watch ออกแบบตามหลักเกณฑ์การระบายน้ำของ สำนักการระบายน้ำ กรุงเทพมหานคร (BMA Drainage Standards)

ข้อมูลสภาพอากาศพยากรณ์ล่วงหน้า 24 ชม. จาก Open-Meteo API (High Resolution Global Models) โดยไม่ใช้อภิมหาคีย์ API

📐

เกณฑ์ประเมินความเสี่ยงน้ำท่วม สำนักการระบายน้ำ กทม.

ระบบท่อระบายน้ำหลักของกรุงเทพมหานครถูกออกแบบตามเกณฑ์มาตรฐานให้รองรับปริมาณน้ำฝนได้ไม่เกิน 60 มิลลิเมตรต่อชั่วโมง (60 mm/hr) หากฝนตกเกินกว่าเกณฑ์ดังกล่าว น้ำฝนจะไม่สามารถไหลลงท่อได้ทันและเกิดน้ำรอระบายหรือน้ำท่วมขังฉับพลัน

🟢 สีเขียว: ปกติ (Normal) < 10 มม./ชม. และ สะสม 3 ชม. < 25 มม.

การระบายน้ำปกติ สัญจรได้ตามปกติ สภาพผิวจราจรแห้งหรือมีน้ำขังเพียงเล็กน้อยตามแอ่งธรรมชาติ

🟡 สีเหลือง: เฝ้าระวังน้ำรอการระบาย (Watch) 10.0 - 35.0 มม./ชม. หรือ สะสม 3 ชม. 25.0 - 50.0 มม.

ฝนปานกลางถึงหนัก อาจมีน้ำขังผิวจราจร 5-10 ซม. ในจุดลุ่มต่ำ ชะลอความเร็วและระวังการลื่นไถล

🟠 สีส้ม: แจ้งเตือนน้ำท่วมขัง (Warning) 35.1 - 60.0 มม./ชม. หรือ สะสม 3 ชม. 50.1 - 80.0 มม.

ฝนตกหนักใกล้เต็มศักยภาพท่อระบายน้ำ กทม. (60 มม.) รถเล็กควรหลีกเลี่ยงซอยต่ำและอุโมงค์ทางลอด

🔴 สีแดง: วิกฤตน้ำท่วมฉับพลัน (Critical) > 60.0 มม./ชม. หรือ สะสม 3 ชม. > 80.0 มม.

วิกฤต! ปริมาณฝนเกินขีดความสามารถในการระบายน้ำของ กทม. เสี่ยงน้ำท่วมสูงเกิน 25 ซม. งดใช้เส้นทางจุดเสี่ยง
